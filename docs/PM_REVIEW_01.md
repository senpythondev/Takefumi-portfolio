## 指摘への回答

### D1. Phase 0 の未完了
- `.claude/` フォルダは始動パックに入っているが、隠しフォルダなのでコピー漏れが起きた。**オーナーが始動パックからコピーする**（Claude Code は書き直さない）。
- `git init` と、ドキュメントだけの最初のコミットは Claude Code が行ってよい。`.gitignore`（node_modules、.env*、.next、テストの生成物）も作る。
- リモートリポジトリは当面**非公開**。公開するかは Phase 7 で決める。

### D2. 外部リンク
- 許可リストを拡張した（`CLAUDE.md` §1-2）：GitHub `https://github.com/senpythondev`、DEV（プロフィール・Genten記事）、LinkedIn（あれば）、メール。
- URLは `src/content/links.ts` に一元管理する。DEVとLinkedInのURLは受領するまで `TODO(fact)` にしておく。
- メールアドレスはHTMLに平文で書かず、クライアント側で組み立てる。コピー用ボタンを付ける。

### D3. 25問レース
- 比較するのは**2構成**（構造化ルール 100%／BM25 72%）。
- 設問ごとの正誤データが届くまでは**最終スコアのバー表示だけ**にする。設問ごとの進み方は創作しない。
- データ（`docs/facts/genten-eval.json`）が届いたら、25マスのグリッドが1問ずつ埋まる演出に切り替える。JSONの形式は Claude Code が提案してよい。

### D4. 深層の8案件
- 技術経歴書の内容は公開してよいとオーナーから確認が取れた。各案件の**技術スタック・役割・規模**と、**スキル評価（A/B/C）**を `BRIEF.md` §6 に追加した。技術マトリクスはこれを元に作る。

### D5. 数値の不一致
- 表記を統一する：「**通常3か月以上**かかる規模を2か月以内で」「**約8年**」（英語は "about 8 years"）。
- 214件と213件は**別の作業の対象数**（214＝URL維持・301転送の対象の投稿、213＝申込導線を入れた記事）なので、統一せずどちらも経歴書どおりに書く。根拠ドロワーでは対象の違いを説明する。

### D6. 特許PDFの透かし（B4）
- **承認**：日本語の透かしは canvas で画像に描き、PNGとしてPDFに埋め込む。フォントはPDFに埋め込まない。
- `pdf-lib` は保守されているフォークに替えてよい。採用前に、ライセンス・最終リリース日・週間ダウンロード数を WORKLOG に記録すること。
- このライブラリは、訪問者がデモを開いたときだけ読み込む（初期JSにもシーンのチャンクにも含めない）。

### D7. ラベル未指定の数値の確度（付録B）
- `BRIEF.md` §6 に「確度ラベルの付け方」を追加した。付録Bの提案をこのルールと照らし合わせ、**食い違うものだけ**を一覧にして報告すること。食い違いがなければ、そのまま承認とする。

### D8. 3Dのサイズ予算の数え方（B6）
- 原則：three.js・R3F・drei などの**共通の3D基盤は「3D基盤チャンク」として1回だけ**数え、上限は 250KB（gzip）とする。各シーンのチャンク（上限250KB）には、そのシーンだけが使うコードと依存だけを数える。どちらも初期JSには含めない。
- B6 の提案がこの原則と同じなら承認。違う場合は、差分と理由を報告すること。

### D9. 守秘チェックの仕組み（B8）
- LLMによるチェック（`confidentiality-guard`）だけに頼らず、**決定的な（毎回同じ結果になる）スクリプトを第一の防御線にする**：
  - `scripts/check-confidentiality.ts`：IPアドレス、AWSアカウントID・ARN・インスタンスID、許可リストにないURL・メールアドレス、画像のEXIFを検出する
  - pre-commit フックと CI の両方で実行し、検出したらコミットとビルドを止める
  - 誤検知を除外するリストは理由つきでファイルに残す
- `confidentiality-guard` サブエージェントは、スクリプトでは判断できない文脈（固有名詞、スクリーンショットの写り込み、AIトレーニングプラットフォームを思わせる記述）の確認に使う。
- B8 の提案と違う点があれば報告すること。

### D10. 実機での計測
- オーナーの手持ち端末はPMが確認中。それまでに、**オーナーが開発ツールなしで計測できる仕組み**を Phase 3 で用意すること：
  - `?debug=1` を付けると、fps（平均・1%低位）、描画回数、ジオメトリ数・テクスチャ数（`renderer.info`）、品質ティア、端末情報を表示するHUDを出す
  - 「10秒間計測」ボタンで結果をJSONとしてコピーでき、オーナーがそれをWORKLOGに貼れるようにする
- 端末が揃ったら、iPhone（Safari）と中価格帯のAndroid（Chrome）で検証する。
